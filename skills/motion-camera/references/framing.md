# Framing

## Seats

- Title seat — x 10–12%, y 16–24%
- Footer seat — x 10–12%, y 76–88%
- UI well — 8% inset rectangle, content scaled contain
- Point — center, 8–16px

## After a punch (1.04)

The well must still show margin. If the UI kisses the frame at rest, it will clip at 1.04. Scale the layer down to ~82–86% width before the camera moves.

## 9:16

Prefer `rest` or `punch`. `lean` and above crop too much vertical UI.

## Anchor cheat sheet

- Cursor demo — anchor toward the click (often 40% 55%)
- Centered app window — 50% 48%
- Object on the right — 62% 50%
